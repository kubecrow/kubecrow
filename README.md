# KubeEyes downloads

This repository only hosts the downloads for [KubeEyes](https://kubeeyes.com), the Kubernetes IDE for macOS.

- **Download:** [latest release](https://github.com/dev-scripts/kubeeyes-releases/releases/latest), or from [kubeeyes.com](https://kubeeyes.com)
- **What's new:** [release notes](https://kubeeyes.com/releases.html)

KubeEyes checks this repository for updates. The source code isn't published here.
