# KubeCrow downloads

This repository only hosts the downloads for [KubeCrow](https://kubecrow.com), the Kubernetes IDE for macOS.

- **Download:** [latest release](https://github.com/dev-scripts/kubecrow-releases/releases/latest), or from [kubecrow.com](https://kubecrow.com)
- **What's new:** [release notes](https://kubecrow.com/releases.html)

KubeCrow checks this repository for updates. The source code isn't published here.
